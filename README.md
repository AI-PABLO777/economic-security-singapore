# Економічна безпека країни — Сингапур

Вебсайт, створений для практичної частини іспиту з дисципліни «Інформаційні технології у системі забезпечення економічної безпеки держави».

- **Автор:** Карнаух Віталій Сергійович (ДТЕУ, ФІТ, F5 «Кібербезпека та захист інформації», магістратура, 2 курс, група 2-7м)
- **Сайт:** https://ai-pablo777.github.io/economic-security-singapore/

## Структура
- `index.html` — головна сторінка (інформація про автора)
- `analysis.html` — аналіз економічної безпеки Сингапуру: ключові показники, таблиці, графіки, порогові значення, тенденції, загрози, висновок
- `css/style.css` — стилі (адаптивний дизайн)
- `js/raw-data.js` — вихідні статистичні дані (World Bank API, SingStat)
- `js/model.js` — порогові шкали, класифікація рівнів безпеки, розрахунки, інтегральна оцінка
- `js/charts.js` — SVG-графіки з інтерактивними підказками
- `js/content.js`, `js/analysis.js` — аналітичний текст і побудова сторінки

Технології: HTML, CSS, JavaScript (без зовнішніх бібліотек).
